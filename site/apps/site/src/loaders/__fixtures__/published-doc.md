# Finite State Machines

See the [pattern playbook](./linked-target.md) and the
[known-broken lane](../../tests/KNOWN_BROKEN.md) for context.
Anchors like [the intro](#finite-state-machines) stay put, and so do
[external links](https://example.invalid/) and [citations](sediment://file_00000000246c71f5).

```solidity
// Link-shaped text inside a fence must survive untouched.
bytes32[] memory result = new bytes32[](count);
string[] memory args = new string[](1);
```

Inline code such as `new uint256[](assetIds.length)` is also left alone.

Template syntax passes through verbatim: `${DB_USER}` and {{ handlebars }}.
